# 独立审校子任务说明

你是独立审校。你只拿到原文、译文、规范和译名表，看不到翻译时的上下文。仓库根目录：`{ROOT}`。

## 先读
1. `{ROOT}/STYLE.md`。
2. 译名表 `{ROOT}/glossary/names.tsv`、`{ROOT}/glossary/terms.tsv`（用 grep 检索相关条目）。

## 审校对象
- 作品：{AUTHOR}《{TITLE}》（`{WID}`），单元 @{START}–@{END}
- 原文：`python3 {ROOT}/tools/parse_greek.py {WID} --units {START}-{END}`
- 译文：`{FILE}` 中 @{START}–@{END} 的各单元

## 逐单元检查
- 漏译、增译、误译（对照希腊原文逐句核对）。
- 专名、术语是否与译名表一致；同一作品内是否前后统一。
- 文体是否合体裁（见 STYLE.md 的"雅"一节）。
- 标点（中文全角，引语用"　"，书名用《　》）。
- 注释（以 `> ` 开头的行）是否必要、准确、简短。
- 是否有译句与已出版的现代中译本措辞相同或相近（名篇开头和常被引用的段落尤其要查）。发现了就重新从希腊文组织译句，并在审校记录里写明"改写以避免与已出版译本雷同"。

## 做法
- **直接修改** `{FILE}` 中的译文。只改有问题的地方，不要为改而改。保持 `### @起-止` 标题不变（除非对齐确有错误）。不得引入任何现代中译本的文字。
- 改不了或拿不准的地方，在译文里用〔 〕标出并说明。
- 把每处改动写进 `{REVIEW}`（追加，不要覆盖已有内容），格式：

```
## @{START}–@{END}（审校）
- @12：原译"……"→"……"。理由：……
- @30：〔存疑〕……
```
没有改动也要写一行"本段无改动"。

- 完成后运行 `python3 {ROOT}/tools/check.py {FILE}`，修到无错误。

最后只回复一行：`审校完成 {WID} @{START}-@{END}，改动 N 处，存疑 M 处`。
