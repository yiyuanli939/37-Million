# 古希腊语专名音译规则

只用于**没有通行译名**的专名。有通行译名的（宙斯、雅典、柏拉图、亚历山大等），一律用通行译名，以 `names.tsv` 为准。

本表以罗念生、王焕生等前辈译者的通行惯例为基础整理（参照的是他们沿用的音译习惯，不涉及任何译本文字）。原则：

1. **按古希腊语读音**，不按拉丁化或英语读音。例如 Κ 一律作 k 音，不读 s。
2. **先查重**：新译名先在 `names.tsv` 里查同名或同词根的条目，同一词根全书用同一组字。
3. **用字从简、避免贬义和生僻字**，人名不刻意用"美字"，女性名可用"娅、丝、娜、拉"等。
4. 一般按音节逐个对音，**不省略音节**；但词尾 -ος/-ης/-ον 等按下面的词尾规则处理。
5. 送气辅音（θ φ χ）与不送气（τ π κ）在汉字上一般不区分。

## 一、词尾

| 希腊词尾 | 处理 | 例 |
|---|---|---|
| -ος（阳性） | 译"斯"，前一音节照常 | Πάτροκλος 帕特罗克洛斯 |
| -ης | 译"斯"，前面元音按 e 音 | Ἀνδοκίδης 安多基德斯；通行译名省去"斯"的（伯里克利）照旧 |
| -ας | 译"斯"，前面元音按 a 音 | Αἰνείας 埃涅阿斯 |
| -ευς | 译"乌斯" | Ὀδυσσεύς 奥德修斯（通行）；Πηλεύς 佩琉斯 |
| -ων（人名） | 译"翁"或"昂" | Κρέων 克瑞昂；Ἀγάθων 阿伽通（通行，例外） |
| -ον（中性） | 译"昂"或"翁" | Ἴλιον 伊利昂 |
| -η / -α（阴性） | 译"娅、拉、娜、塔"等，或以"亚、厄"收尾 | Πηνελόπεια 佩涅洛佩；Ἑλένη 海伦（通行） |
| -ις | 译"伊斯" | Θέτις 忒提斯 |
| -υς | 译"于斯"或"斯" | Τηθύς 特提斯 |
| -ειον / -ιον（地名） | 译"昂" | Σούνιον 苏尼昂 |
| 族名 -οι / -ες | 先取单数音译，再加"人" | Ἀχαιοί 阿开奥斯人 |

地名一般不带"斯"之外的意译成分；需要意译的（"山""河""岛"）只在通行译名里保留。

## 二、辅音

| 希腊字母 | 拉丁转写 | 常用汉字 |
|---|---|---|
| β | b | 布、贝、比、波 |
| γ | g（γγ γκ 中为 ng） | 格、伽、吉、戈 |
| δ | d | 德、达、狄、多、杜 |
| ζ | z | 宙、泽、佐 |
| θ | th | 特、忒、提、托、图 |
| κ | k | 克、卡、基、科、库 |
| λ | l | 勒、拉、利、洛、卢 |
| μ | m | 姆、墨、玛、弥、摩、穆 |
| ν | n | 恩、涅、纳、尼、诺、努 |
| ξ | x（ks） | 克斯、克塞、克西 |
| π | p | 普、佩、帕、皮、波 |
| ρ | r | 尔、瑞、拉、里、罗、鲁 |
| σ ς | s | 斯、塞、萨、西、索 |
| τ | t | 特、忒、塔、提、托、图 |
| φ | ph | 菲、费、法、福 |
| χ | ch（kh） | 克、卡、喀、基、科 |
| ψ | ps | 普斯、普绪 |
| 送气符 ῾ | h | 赫、哈、希、霍 |

辅音在音节末（不跟元音）时用"克、斯、德、普、尔、姆、恩"等单字收尾，或与后一音节合并。

## 三、元音与复合元音

| 希腊字母 | 读音 | 常用汉字（与辅音配合） |
|---|---|---|
| α | a | 阿、拉、卡、塔…… |
| ε η | e / ē | 厄、埃、勒、忒、墨…… |
| ι | i | 伊、利、提、尼…… |
| ο ω | o / ō | 俄、奥、洛、托、诺…… |
| υ | y（ü） | 于、绪、许 |
| αι | ai | 埃、艾 |
| ει | ei | 埃、伊 |
| οι | oi | 奥伊、俄 |
| ου | u | 乌、努、鲁…… |
| αυ | au | 奥 |
| ευ | eu | 欧、尤 |

开头的元音配不送气符时，α 作"阿"，ε/η 作"厄、埃"，ι 作"伊"，ο/ω 作"俄、奥"，υ 作"许、绪"（υ 开头必有送气符）。

## 四、处理顺序

1. `names.tsv` 中有，直接用。
2. 有通行的中文译名（中文学界和百科普遍采用的），用通行译名并登记，`来源` 记为"通行"。
3. 都没有，按本表逐音节音译并登记，`来源` 记为"音译"。
4. 同名不同人，加括注区分，例如"狄奥尼修斯（叙拉古僭主）"。
5. 修饰语（如 γλαυκῶπις"灰眼睛的"）、族名、神的别号同样登记，全书统一。
