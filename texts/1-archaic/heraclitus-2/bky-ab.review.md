# 审校记录：以弗所的赫拉克利特《论万物的本性（残篇）》（bky-ab）

## 翻译时的存疑
- @2：ἀεί 可连上（逻各斯始终存在）或连下（人们始终不领会），译文取连上读法，注中说明。
- @11：συνάψιες 抄本另作 συλλάψιες（被一同把握者），译’结合者’。
- @13：’灵魂也从湿气中蒸发出来’是否属赫拉克利特原话，原文已标(?)。
- @42：ὁτέη 为校订读法，抄本作 ὅτε ἡ 等，另有校作 ὅκη；译文按’驾驭万物的识见’理解。
- @53：παλίντροπος 另一传本作 παλίντονος（反向张紧），注中说明。
- @60：ἐπαιτέονται 为 Bernays 校读（索取），抄本作 ἐπαιτιῶνται（抱怨）。
- @61：γναφείωι 校读，抄本作 γραφέων（书写者）。
- @65：ἔνθα δ’ ἐόντι ἐπανίστασθαι 原文可能有讹，意义不明，按’在那里的那一位面前起身’试译。
- @69：〈πῦρ〉为狄尔斯补字，另有补〈ἔλαιον〉（油）者。
- @88：ἄρχεσθαι 可解为’受统治’或’开始’，译文取前者。
- @99：Diels 认为普鲁塔克只引了前半句为赫拉克利特语，后半 ἔργον δὲ ἐν ἀνέσει καὶ παρ’ οἶνον 为普鲁塔克语，故只给前半加引号。
- @108：ξυνόν 本义“共同的”，此处译“相通”，表示开端与终结在圆周上属于同一点。
- @118：ξὺν νόωι 与 ξυνῶι 为双关，加注说明。
- @122：原文 oder vielmehr 为整理者的德文按语，表明 αὐγὴ ξηρὴ 与 αὔη 两种读法；两种都译出。
- @124：οὖρος 一义“界标”，一义“守望者”，取前者。
- @132：阿纳托利奥斯引文费解，σημείω 为双数，译“两个标志”；ἄρκτους 复数，译“两熊星”。
- @133：纸草残损，〈〉内为整理者补字，译文照其补字译出并保留〈〉；“赫拉〈克利特〉的〔说法〕”中〔〕为译者补字。
- @138：οἴησιν 原义“自负、自以为是”；προκοπή 与 ἐγκοπή 是同根文字游戏，加注。
- @143：καθερώτεραι 当为 καθαρώτεραι 之误，原文标 (so)，译作“（原文如此）”。


## @1–@146（审校）
- @30：原译"最优秀的人宁取一样而舍弃其余一切，那就是凡人中间永流不息的名声；而多数人却像牲畜一样只顾填饱肚子"→"最优秀的人舍下一切，只选一样：在凡人中间长流不竭的名声；多数人却如同牛羊，吃饱了便罢"。理由：改写以避免与已出版译本雷同。
- @31：原译"这个宇宙对所有〔存在者〕都相同……它一向是、现在是、将来也永远是一团长生的火，燃起有其定量，熄灭有其定量"→"这个宇宙，于万物同为一个……它从来就是、如今仍是、往后也将是永生不灭之火，按定量点燃，按定量熄灭"。理由：改写以避免与已出版译本雷同。
- @34：在"法律"后补括注（νόμος）。理由：本作品中 νόμος 首次出现在此单元，按 STYLE.md 首次括注。
- @37：原译"对灵魂而言，死就是变成水；对水而言，死就是变成土；而水从土中生成，灵魂从水中生成"→"灵魂的死，是成为水；水的死，是成为土；可是土里生出水，水里又生出灵魂"。理由：改写以避免与已出版译本雷同。
- @45：原译"人民应当为法律（νόμος）而战，如同为城墙而战"→"民众应当护卫法律而战斗，正如护卫城墙"。理由：改写以避免与已出版译本雷同；括注已移至 @34。
- @46：原译"灵魂的边界，你即便走遍每一条路，也找不到；它的逻各斯就有这样深"→"纵然踏遍每一条道路，你一路走去也寻不到灵魂的尽头：它所含的逻各斯深邃至此"。理由：改写以避免与已出版译本雷同。
- @83：原译"应当知道，战争是共通的，正义就是争斗，万物都依照争斗和必然而生成"→"要懂得：战争为一切所共有，正义即是争执，一切事物都经由争执、凭着必然而生成"。理由：改写以避免与已出版译本雷同。
- @86：原译"人当中最有智慧的，与神相比，无论在智慧、美貌还是其他一切方面，都会显得是一只猴子"→"人类里最智慧的，放到神面前，论智慧、论容貌、论其余种种，都会现出一副猴相"。理由：改写以避免与已出版译本雷同。
- @87：原译"它在变化中得到休息"→"变动着，它便安歇"。理由：改写以避免与已出版译本雷同；也更贴近分词结构 μεταβάλλον ἀναπαύεται。
- @94：原译"万物换火，火换万物，就像货物换金子、金子换货物一样"→"万物都可兑成火，火也可兑成万物，好比金子兑成货物，货物兑成金子"。理由：改写以避免与已出版译本雷同。
- @95：原译"同一条河流，人不可能踏进两回"→"同一条河不容人两度涉足"。理由：名句，改写以避免与已出版译本雷同。
- @100：原译"尸体比粪便更该扔掉"→"死尸比粪土更该丢出门外"。理由：改写以避免与已出版译本雷同（ἐκβλητότεροι 本义"更该被抛出去"）。
- @103：原译"倘若没有太阳，就算有其余的星辰，也还是黑夜"→"要是太阳不在，单凭其余的星辰，那仍旧是夜晚"。理由：改写以避免与已出版译本雷同。
- @113：原译"我听过许多人的言论，其中没有一个人达到这样的地步：认识到智慧的东西是与一切分离的"→"凡我听过其言论的人，无一走到这一步：明白那智慧者独立于万物之外"。理由：改写以避免与已出版译本雷同；原文 ὁκόσων 是"凡……者"，并无"许多"。
- @119：原译"灵魂有一种自我增长的逻各斯"→"灵魂所具的逻各斯，是使自身增长的"。理由：改写以避免与已出版译本雷同。
- @122：注释"第尔斯"→"狄尔斯"。理由：与 @4、@13 的"狄尔斯"统一。
- @132：λόγος 译"比例"→"比"。理由：按 terms.tsv，指比例时译"比"。
- @143：原译"死于战神之手"→"死于阿瑞斯之手"。理由：ἀρηίφατοι 与 @25 同词，作品内统一。
- @144：原译"埃提乌斯"→"阿埃提奥斯"。理由：按 names.tsv 并与 @4 统一。
