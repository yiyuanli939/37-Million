# 审校记录：莱斯沃斯的萨福《致阿佛洛狄忒颂歌及诸残篇》（apu-ab）

## 翻译时的存疑
- @1：首词papyrus作 ποικιλόθρο[ν'，另有抄本读 ποικιλόφρον'（心思斑斓的）；从 ποικιλόθρονος 译“坐在绚彩宝座上的”。
- @6：πείθω .].σάγην 残坏，通常校作 ἄψ σ' ἄγην（引回），按“把她引回你的爱中”译出。
- @9：δευρυμμεκρητας 连写，按 δεῦρύ μ' ἐκ Κρήτας（从克里特到我这里）理解；κῶμα καταγριον 应读 καταρρεῖ（流下），从之。τωτ...ιριννοις 按 ἠρίνοισιν（春天的）理解，标〔?〕。
- @10：στέμ〈ματ'〉 为补字，“花环”标〔?〕。
- @36：τὸν [ ].στον 缺字，常补 ἄριστον（最高贵的），标〔?〕。
- @50：..].γυλα 按 Γογγύλαν 补读，]κτιν 按 πᾶκτιν（竖琴）补读，均标〔?〕。
- @126：επιδωμον 讹误，各家校法不一（如 ἐπὶ βῶμον），译作“〔在祭坛上〕”。
- @133：ἀ.[..]–¨νάω 残缺，按 ἀεννάω（长流不息的）补读，标〔?〕。
- @145：ἐπόησας 后常补 καλῶς 或理解为“做得好”，标〔?〕。
- @178：末两行据补字译出；新出科隆纸草所载提托诺斯诗与此本不同，按本本译。
- @290：Ὤιρανα 作人名解（Εἰράνα），译埃拉娜；@394 同。@394 亦有人不作专名，而解作形容词。
- @270：古注残坏，‘ειρηκε τη[ν] πειθω’ 推测为称佩托为阿佛洛狄忒之女，仅译出可辨词语。
- @304：‘]μας γ’ εἴσηλθ’’ 一般补作 [Ἔρ]μας（赫尔墨斯），译文加〔〕。
- @307：‘θεασικελαν ἀριγνωτα’ 读作 θέαι ἰκέλαν ἀριγνώτᾳ（如显赫的女神），也有人以 Ἀριγνώτα 为人名。
- @341：‘φέρεις ἄπυ μάτερι παῖδα’ 译作‘把孩子从母亲身边带走’（与卡图卢斯第62首相合）；也有校订作‘把孩子带回母亲身边’。
- @377：‘αυταόρα ἐστεφαναπλόκην’ 原文有讹，暂读作 αὔτα ποτ’ ἐστεφαναπλόκην（我自己曾编织花冠）。
- @400：Κυθέρη 在此指阿佛洛狄忒，按 Κυθήρη/Κυθέρεια 译库忒瑞亚；names.tsv 中 Κυθέρη 另有‘库忒瑞（人）’一条，所指不同。
- @328：‘καγγόνων’‘καταυταμενἀτατιμάσεις’ 原文讹误，无法确解，只译可辨部分。
- @412：ἄωρος 据阿忒奈俄斯引文的解释作‘睡眠’讲。


## @1–@468（审校）
- @1：原译"宙斯的孩子，编织诡计的女神，我向你恳求：女王啊，不要用烦恼和痛楚压垮我的心灵"→"宙斯所生的女儿，罗织机巧的女神，我恳求你：女王啊，别拿忧伤和苦楚来制伏我的心灵"。理由：名篇开头，原译措辞与已出版译本相近，改写以避免与已出版译本雷同；δάμνα 意为"制伏"。
- @11：原译"你就在那里取下花环〔?〕……斟上……琼浆"→"就在那里，请你拿起花环〔?〕……斟出……琼浆"。理由：οἰνοχόαισον 是命令式（祈使），原译读成陈述；ἔλοισα 是"拿起"而非"取下"。
- @50：〔存疑〕"……ανθι λάβοισα"中的 …ανθι 常被补作呼格人名 Ἀβανθίς（阿班提丝），则句意为"我吩咐你，阿班提丝，拿起竖琴"。译名表未收此名，正文未补，只在译文中以〔 〕和注标出。
- @111：原译"我比青草还要苍白"→"我比草叶还要青白"。理由：名句，原译与已出版译本措辞相同，改写以避免与已出版译本雷同；χλωροτέρα 兼有青、白之义。
- @117–@119：原译"群星环绕着美丽的月亮，每当她最圆满的时候，就又把自己闪亮的容貌掩藏，她照亮大地"→"环绕美丽月亮的群星又把自己闪亮的形貌隐去，每当她盈满到极致，照亮大地"。理由：原译"每当她……"与"就又把自己……"主语混淆（隐去光芒的是群星，盈满的是月亮）；行序也更贴近原文；同时改写以避免与已出版译本雷同。
- @147–@148：原译"阿提丝啊，我曾经爱过你，那是很久以前……那时你在我眼里，还是个瘦小、不懂风情的孩子"→"阿提丝，我早年便对你动了情，那已是久远的往昔……那时你在我看来，不过是个瘦小、毫无风韵的孩子"。理由：改写以避免与已出版译本雷同；ἄχαρις 是"无风韵、不可爱"，不是"不懂风情"。
- @149：原译"美的人，只在被人看见的那一刻是美的；而善的人，当下就是美的，将来也会是美的"→"俊美的人，其美只及于目光所见；而良善的人，此刻便美，往后也将美"。理由：改写以避免与已出版译本雷同；ὄσσον ἴδην 是"就所见而言"，非"那一刻"。
- @150：原译"我不知道该怎么办：我的心意分成了两半"→"我拿不定该做什么：我的心思一分为二"。理由：改写以避免与已出版译本雷同。
- @308–@309：原译"……月亮 / 胜过周围 // 所有的星辰"→"……月亮 / 把一切 // 星辰都比了下去"。理由：对齐。πάντα 在 @308，περρέχοισ’ ἄστρα 在 @309，原译把两者在单元间颠倒了。
- @312–@313：原译"心 / ……被啃噬着"→"心或许……正被啃噬着"。理由：@312 原文只有 ποι（"或许"），原译漏译。
- @329–@330：原译把"对一个少年的思念"放在 @329→改为 @329"思念制服了我——"，@330"对一个少年的思念，都怪那纤柔的阿佛洛狄忒"。理由：对齐。παῖδος 在 @330。
- @340–@341：原译"你都带回：你带回绵羊，你带回山羊，你把孩子从母亲身边带走"→"你都领回：你领回绵羊，领回山羊，却把孩子领离母亲身旁"。理由：名篇，改写以避免与已出版译本雷同；保留原文 φέρεις 的三次重复。
- @343：原译"就像那颗甜苹果，在枝梢上泛红，在最高的枝头上，高高地，摘果的人把它忘了——不，不是忘了，是够不着它"→"恰似那只蜜甜的苹果，在高枝的梢头红透，在最高处的顶端；采果人把它遗落了——其实并未遗落，只是无从攀及"。理由：名篇，原译末句与已出版译本几乎相同，改写以避免与已出版译本雷同。
- @364：原译"龟甲琴"→"龟壳琴"。理由：与 @175（χελύννα，已加注"龟壳琴"）统一。
- @387–@389：原译"我有一个美丽的孩子，她的模样就像金色的花朵，心爱的克勒伊丝，为了她，我不〔愿换取〕整个吕底亚，也不〔要〕可爱的……"→"我有个孩子，生得美，容貌恰如金色的花朵，是我心爱的克勒伊丝；拿她来换，我也不要吕底亚——整个吕底亚都不要，可爱的……也不要……"。理由：名篇，原译与已出版译本相近，改写以避免与已出版译本雷同；并对齐：παῖσαν（"整个"）在 @389。
- @392：原译"我在俄涅洛斯里与塞浦路斯所生的女神交谈"→"我在梦中与塞浦路斯所生的女神交谈"。理由：误译。ὄναρ 是副词性名词"在梦中"，不是梦神俄涅洛斯（Ὄνειρος）。
- 其余单元：本段无改动。
