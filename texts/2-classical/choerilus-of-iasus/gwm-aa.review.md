# 审校记录：伊阿索斯的科伊里洛斯《残篇与题名》（gwm-aa）

## 翻译时的存疑
- @3：原文以 * 和 { } 标出 ἥδε … χρυσόν 数行，通常视为后人续加（或为克拉特斯的戏仿相关文字），译文保留花括号。
- @1：原文单元在句中切断，为保持句子完整，把 @1–6 合为一个对齐单元。


## @1–@6（审校）
- @3：原译"我所留有的，只是我吃下的，我纵情挥霍的，以及在爱欲中／享受过的欢愉；而那许多富丽的财宝，都已撇在身后。"→"如今归我的，只有吃进口中的、恣意放纵过的，和在爱欲里／尝到的甜美；那许多丰饶的财富，却都已撇在身后。"。理由：此为萨尔达纳帕洛斯墓志铭的名句，常被引用，改写以避免与已出版译本雷同；同时 ἐφύβρισα 指恣意放纵，而非"挥霍"，τερπνά 译"甜美"，ὄλβια 译"丰饶的财富"，更贴原文。
- 其余诗行本段无改动；花括号内后人增补的诗行照原文保留。
