# 审校记录：颂歌集无名氏《颂歌第四：致赫尔墨斯》（upu-bb）

## 翻译时的存疑
- @41：ἀναπηλήσας 意义不明（或读 ἀναπειλήσας 等），一说“翻转过来”，一说“剜出”；译作“把它翻过来”。
- @86：αὐτοτροπήσας 为罕见词，意义有争议（“自出心裁”“转身”）；85–86 两行整体文意难解，依“为避人察觉而自想办法”译出。
- @103：ἀδμῆτες 一说应读 ἀκμῆτες（不知疲倦的），今按“未经驯服”译。
- @109：多家认为 109–110 之间有脱文（缺另一块取火木的描写），译文照现存文字译出。
- @130：ὁσίης κρεάων 解释有争议：“祭肉”“合于礼可食的肉份”或“分肉的仪式”，译作“祭肉”。
- @188：κνώδαλον（野兽）在此难以成句，或为讹误；或解作老人所牧的牲口。译作“放牧牲口”，“整治”为补字。
- @284：οὔ χ’ ἕνα μοῦνον ἐπ’ οὔδεϊ φῶτα καθίσσαι 意指把屋里东西偷光、让人只能坐在地上，译文略作意会并加注。
- @325：εὐμιλίη 为罕见词，或读 ὁμιλίη/ἀμιλίη；按“和睦欢聚”译出。
- @357：διαπυρπαλάμησεν 为孤例词，大意为“巧施手段、迅速弄妥”，按“施展了诡计”译出。
- @409：绞绳者主语不明，按上下文理解为阿波罗（欲捆赫尔墨斯或牛），绳索却在牛脚下生根；不少校本认为此处前后有脱文。
- @416：ἐγκρύψαι μεμαώς 缺宾语，诸家疑 415 行后有脱文（赫尔墨斯欲藏何物不明），译文作“藏起〔……〕”。
- @418：λαβών 缺宾语（琴），补〔琴〕。
- @473：本句缺 σε（“你”），按通行理解“我知道你在这些方面是个富有的孩子”译出。
- @526：526 行起由间接叙述突然转为阿波罗的直接引语，且 ποιήσομαι 缺宾语，疑有脱文；补〔你〕并加引号。
- @569：569–573 行转为不定式结构（ἀνάσσειν κύδιμον Ἑρμῆν），说话人或主语不明，疑有脱文；译作叙述，补〔他还定下：〕。
- @573：ἄδοτος 指哈得斯“不受礼物”（或“不给予”），按前者译。


## @1–@580（审校）
- @181：原译结尾引号误作左引号"看到。“"→"看到。”"。理由：标点错误。
- @200：原译"路上？“"→"路上？”"。理由：右引号误作左引号。
- @211：原译"他自己。“"→"他自己。”"。理由：同上。
- @277：原译"罢了。“"→"罢了。”"。理由：同上。
- @284：原译"让不止一个人光身坐在地上"→"让不止一个人只能坐在光秃秃的地上"，注释相应改。理由：ἐπ’ οὔδεϊ φῶτα καθίσσαι 只说"使人坐在地上"（家当被偷光），"光身"（赤身）为原文所无。
- @292：原译"首领。“"→"首领。”"。理由：右引号误作左引号。
- @297–298 注：原注"上一行的'鸟兆'（'肚腹的奴仆'）一般理解为放屁"删去，只留"古希腊人视喷嚏为预兆"。理由：与 @293–296 正文（"预兆""肚子的苦命雇工"）用语不符，且 @296 已有同义注释，重复。
- @336–339 注：删去"库勒涅：阿卡狄亚北部的山"。理由：@1–9 已注，且两注方位（东北部/北部）互相矛盾。
- @344–349 注：删去"阿福花：日光兰属植物……"。理由：@219–226 已注，两注说法不一，重复。
- @363–364：阿波罗转述赫尔墨斯的话，原用半角 ' ' 及错误的右引号"'“"→改为全角单引号‘ ’并以”收结。理由：引语中的引语用全角单引号，标点规范。
- @382：原译"我爱你，也提防着他"→"我爱你，也敬重他"。理由：ὀπίζομαι 意为"敬畏、尊重"，不是"提防"。
- @416–418：原译"而勒托光荣的儿子、远射的神，他却轻轻松松就让他平息了下来……尽管那神十分强大"→"可他轻轻松松就安抚了勒托光荣的儿子、远射的神，正如他自己所愿，尽管那位神十分强大"。理由：原译主语、宾语不清，易误读为阿波罗使赫尔墨斯平息；原文 ἐπρήϋνεν 的主语是赫尔墨斯。
- @543–544：原译"凡是凭着鸣声和飞翔都能应验的鸟前来的人"→"凡是循着应验之鸟的鸣声和飞翔前来的人"。理由：原句结构混乱；φωνῇ τ’ ἠδὲ ποτῇσι τεληέντων οἰωνῶν 是"应验之鸟的鸣声和飞翔"。
- @550–566 注：删去"后世或称为'特里埃'"，改为"以蜂蜜为食、能作预言的蜂形少女"。理由：该名不见于原文，也未登记译名表，属学术推测，不宜入简注。
- @568：原译"骡子。“"→"骡子。”"。理由：右引号误作左引号。
- @573：原译"那位神虽不收礼"→"哈得斯虽不收礼"。理由：ἄδοτός 指哈得斯，原译代词所指不清。
- @79–86：〔存疑〕@85 ὁδοιπορίην ἀλεείνων 原译"为了避开〔被人察觉的〕行迹"，此行文意素有争议（或解作"避免长途跋涉的劳顿"），保留原译。
- @414–416：〔存疑〕@416 ἐγκρύψαι μεμαώς 后通常认为有脱文，原译以"〔……〕"标出，保留。
- 其余各单元对齐无误，专名与译名表一致；未发现与已出版中译本雷同的译句。
