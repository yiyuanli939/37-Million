# 审校记录：阿里斯托芬《市井家常残篇》（daw-af）

## 翻译时的存疑
- @11：νῆς 费解，疑有讹误，译文以〔……〕表示所欲之物不明。
- @13：原文 δρῶσαιλαμβανόμεσθ’ 两词连写，当作 δρῶσαι λαμβανόμεσθ’ 理解。
- @134：μολγός 为皮囊，句意费解，或为双关；按字面译。
- @168：θερμούς 可解为'热的（面包）'或'羽扇豆'，取前者，注中说明双关。
- @230：πόλος 此处取'日晷'义；πόστην 后所省名词不明，补'条线'。
- @336：νεβλάρετοι 词义不明，据上下文猜作'新征来的'。
- @364：μνοῦς 或为'绒毛'，或为'一谟那'之讹，取前者。
- @396：προσπράττωσι γραῦν 句意不明，译作'逼我收下个老太婆'。
- @436：ἡλίσκον 取作 ἧλος 的指小词'小钉子'。
- @447：διόπας、πλάστρα、μαλάκιον 等饰物名称确义不明，按词源推译。
- @223：此单元与 @1 原文完全相同（同一残篇重出），译文从同。
- @496：开头 παρέσο 不成词，疑有讹误，译作省略号。
- @480：βρῶμ' 可解作'菜肴'或'臭味'，取前者；整段句读不定。
- @515：ἀπεχρήσαντο 可解作'用尽'或'杀死'，译作'用完了事'兼顾两义。
- @581：ἐκαυλίζοντο 字义'长出茎秆'，所指（和平时兵器改作他用？）不明，照字面译。
- @658：θησομύζειν 词义不明，暂按'在忒修斯庙嘟囔'理解。
- @665：ἵνα κάμνοι 的主语不确定，暂取'吃无花果者本人'。
- @694：[κόσκινον] 为整理者删字，译文以〔筛子〕标出。
- @699：πεζίς 词义不确定（船名或鞋名），暂译'平底小船'。
- @714：Ἰσθμιακά 所指物件不明，补作〔头饰〕。
- @874：ἀναστοιχήσας ἄνω 与 φθέγμα κεκράτηκε 意义费解，照字面译。
- @884：τὴν φάρυγα μηλῶν 句意不明，照字面译。
- @900：ἐκβαίνετον τὸν πατέρα 可解为'胜过父亲'或'把父亲送出'，取前者。
- @911：σᾶ 可读作'安然无恙的'（σῶα）或'你的'，取前者。
- @922：ἐξ ἀποτρόχων 词义不明，按'小跑'理解。
- @939：句意不明，照字面译。
- @940：ὑπερῶ 词义不确定（'违背'或'越过'），照字面译。
- @944：κῆχος 不成词，疑有讹误，译作省略号。
- @999：θέρμαν 可解作'热炭/热量'或误作 θέρμον（羽扇豆），取前者。
- @1005：μολγοί 古辞书或释为'皮口袋'，或释为'偷挤奶者、窃贼'，取前者。
- @1034：ὀ πίττομαι 文本可疑，暂译'被涂上沥青'加〔?〕。
- @1064：βελέκκων 或为一种豆类，加〔?〕。
- @1077：δράψ 义不确，或同 δράπης（逃跑者、坏蛋），加〔?〕。
- @1092：ἡμιφωσώνιον 义不确（半块麻布或帆布），加〔?〕。
- @1111：λεγωνῆσαι、ξειρης、σαικωνίσαι、σεῖν、φνεί、νοβακκίζειν（@1111、1134、1151、1152、1187、1250）均为孤立且义不明的词条，只标'义不明'。
- @1215：原文 [ἤτοι Φάλτον] 为整理者认定的衍文或注解，译文以〔即法尔托斯〕表示。


## @1–@1262（审校）
- @64-65：原译"再吃一只用细芦秆捉来的小蝉"→"再吃一只我自己用细芦秆捉来的小蝉"。理由：θηρευσαμένη 为说话人（女性）自己捕捉，原译漏掉主语。
- @67-69（注）：原注"其名意为'鹧鸪'"→"其名意为'山鹑'"。理由：πέρδιξ 为山鹑；"鹧鸪"已用于 ἀτταγᾶς（@622），避免混淆。
- @82（注）：原注"特潘德罗斯"→"特尔潘德罗斯"。理由：依译名表 Τέρπανδρος。
- @109：原译"船尾的缆绳"→"系舵的绳索"。理由：ἐπίγυον 与 @615 统一译法。
- @188-189：原译"五科斯的"及注"科斯：……约合三升余"→"五孔斯的"，注"孔斯：液量单位，约合三点二升"。理由：依术语表 χοῦς 译"孔斯"。
- @268-275（注）：原注"父亲用老派的词骂儿子守旧，儿子则随口用时兴的演说词"→"儿子满口时兴的新词，父亲逐一指出这些词的来处"。理由：原注与正文不符，σορέλλη 等词是儿子骂父亲的新词，指出出处的是另一方。
- @300-302：原译"《希俄斯酒，来自拉科尼亚女子》"→"'希俄斯酒，盛在拉科尼亚杯里'"，并改注。理由：Λάκαιναι 指拉科尼亚式酒杯；是否为酒歌起句无从确定，注中改为"或为"。
- @316-318：在"那么，让你的儿子"前加破折号，并改注。理由：后半句是儿子反问，说话人已换；原注"父亲考问两个儿子"与正文不符。
- @406-409：原译"我是人人喜爱的厄瑞涅 / 最忠实的保姆"→"人人都爱的厄瑞涅，我是她的 / 忠实保姆"。理由：原译易误读为"我是厄瑞涅"；πιστή 不是最高级，原译增译了"最"。
- @441-442：原译"胞衣糕"→"奶蜜糕"。理由：χόριον 与 @815-825 统一译法。
- @447-449：原译"脚镣""胸带"→"脚环""裹胸带"。理由：πέδαι 在饰物清单中指脚环；ἀπόδεσμοι 与 @445 的 στρόφιον（胸带）区分，并与 @465-468 的"裹胸的束带"一致。
- @515-517：原译"统统用完了事"→"统统结果了"。理由：ἀπεχρήσαντο 此处指杀死（见注），原译意思不明。
- @577-578：原译"你今天 / 要遭什么罪"→"今天你 / 将遭受什么"。理由：与 @412-413 同一诗行，译文统一。
- @590-595：原译"在我们这儿是个弓手，却在你们那里……当年轻人的辩护人"→"我们这儿有那么一个可恶的弓手辩护人，就像欧阿特洛斯……在你们年轻人中间那样"。理由：τοξότης συνήγορος 是一个称呼，原译把它拆成两种身份并分属两处，增出了"却"的转折；ὥσπερ Εὔαθλος 是比较。
- @650-651：原译"看来你是带着火来添火"→"看来我这是火上添火"。理由：ἔοικ' ἥκειν ἄγων 的主语是交出淮德拉的说话人本人。
- @1005：原译"皮口袋"→"皮囊"。理由：μολγός 与 @134 统一。
- @1009-1010（注）：删去"此处同名而非墨勒阿格罗斯之父"。理由：这句与正文无关，也没有必要。
- @1083：原译"他做了外侨的保护人"→"他充当了〔外邦的〕代理人"。理由：πρόξενος 是在本邦代表外邦利益的公民，不是外侨的保护人。
- @1162：原译"斯特瑞普赛奥斯人"→"斯特瑞普萨人"。理由：依译名表 Στρεψαῖοι，并与 @166 统一。
- @1196-1197：译文统一为与 @499-500 相同的"难道你们之间 / 吵过架？——绝对没有，我一句话也没说。"理由：同一诗行重复出现。
- @1200：原译"澡堂伙计用水勺推搡着人"→"浴工拿着舀子推推搡搡"。理由：与 @624 同一诗行，译文统一。
- @396-398：〔存疑〕προσπράττωσι γραῦν οἱ φράτερες 义未详（可能是"胞族的人为一个老太婆向我索取费用"），保留原译，并在正文加〔此句义未详〕。
- @11：〔存疑〕νῆς 疑有讹误，原译已用〔……〕标出，保留。
- 对齐：逐单元核对 ### 标题，未发现诗行错位。所查名篇开头（如 @1、@205 戏仿《赫卡柏》）未见与已出版译本雷同的措辞。
