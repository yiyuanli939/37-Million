# 审校记录：欧里庇得斯《安德洛玛刻》（cbm-aj）

- @226：προσίσταται 有 crux 标记，按'在你能轻易做到的限度内'理解译出。

- @563：ἄδουλα δώμαθ’ ἑστίας 有 crux 标记，按'门不上锁、不留奴仆看守'理解译出。
- @572：Φίλιον 一读作 φίλον（'抛下你的爱'），此从大写，译'友谊之神'。

- @748：〈τὸ〉为整理者补入的冠词，汉语无对应字，不另标出。
- @760：方括号行'因要杀不该杀的人而被处死'疑为窜入，照译保留。
- @797：〈ἢ〉为整理者补字，译文作'〈或〉'保留补字符号。
- @822：方括号行疑为窜入（与上行意思重复），照译保留。
- @880：方括号行'巧言、奸诈、花样百出的饶舌'疑为窜入，照译保留。

## @1–@625（审校）
- @2：原译"亚细亚大地的荣饰，忒柏城啊，"→"忒柏之城啊，你是亚细亚土地上的华饰，"。理由：名篇开头，出于谨慎重新组织译句，改写以避免与已出版译本雷同；意思不变（σχῆμα 装点、华饰）。
- @290–@299：对齐错误。原标题 @290-298 / @299-299 / @300-309 / @310-313 整体错位一行：@298 是说话人标记 ΜΕΝΕΛΑΟΣ，@299 才是墨涅拉奥斯台词首行，@309 是安德洛玛刻"ὦ δόξα δόξα"一行。改为 @290-297（合唱）/ @298-298（墨涅拉奥斯）/ @299-308（墨涅拉奥斯台词）/ @309-313（安德洛玛刻），译文内容未动。
- @132、@138：原标"首节""次节"→"第二首节""第二次节"。理由：这是第二对首节、次节，与本段 @456、@463 的标法统一。
- @284、@290：同上，"首节""次节"→"第二首节""第二次节"。
- @339–@340：原译"也不愿遭受我所说的这些事"→"也不愿她遭受我所说的这些事"。理由：παθεῖν 的主语是女儿，原译读来像是墨涅拉奥斯本人遭受。
- @346–@349：原译"是有意为之，并非无心，那么我也不会／伏倒在祭坛边求庇，而要亲自领受惩罚，／受你女婿的惩罚——我使他无后，／欠他的损害并不比这更轻。"→"那么我会心甘情愿、毫不勉强，也不伏倒在／祭坛边求庇，亲自去领受审判，／在你女婿面前受审——我使他无后，／欠他的赔偿并不比欠你的更轻。"。理由：ἑκόντες οὐκ ἄκοντες 修饰的是 αὐτοὶ τὴν δίκην ὑφέξομεν（甘愿受审），不是修饰下药；ἐν σοῖσι γαμβροῖς 指在女婿面前受审；οὐκ ἐλάσσονα βλάβην 是和欠墨涅拉奥斯一家的相比。
- @352–@354 注：原注"“射尽”一句"→"“射得一干二净”一句"。理由：注里引的词要和正文一致。
- @411：原译"把她的双手反绑起来"→"用胳膊把她箍紧"。理由：ἀμφελίξαντες χέρας 是阳性复数，说的是仆人们张开手臂把她箍住，原文没有"反绑"。
- @440 注：把"逼成了水手"一条注从 @444-446 移到 @437-443，与它所注的 @440 放在同一单元。
- @191：〔存疑〕原文有 crux（τύχηι θ’ ὑπερθεῖ），译文已用〔也被它胜过〕标出，取"特洛伊在运道上也胜过斯巴达"的读法。另一种读法是把它理解为安德洛玛刻自称"在运道上胜过你"。保留原译。
- @226：〔存疑〕原文 προσίσταται 有 crux，按"你能轻易做到的范围内"理解，保留原译"只要你能轻易做到"。
- @449–@452：原文多处 crux（ἔριδας、γάμοις、εὐνάν、οὐδὲ γὰρ ἐν），译文按通行读法译出，没有改动。

## @626–@1206（审校）
- @656：原译"这样做远远是最好的"→"这样做要好得多"。理由：λῷστα μακρῷ 译法生硬，改为通顺的汉语。
- @742–750（注）：原注"其名'好客之海'原称'不好客之海'，此处暗用"→"黑海古称'不好客之海'，后改称'好客之海'"。理由：原注表述颠倒含混。
- @844：原译"愿你让她解脱苦难"→"愿你赐下苦难的解脱"。理由：πημάτων δοίης λύσιν 未指明受者，"让她"为增译。
- @913：原译"神灵（δαίμων）"→"神灵"。理由：δαίμων 已在本作品 @1–625 段首次括注，不再重复。
- @947：原"歌队：／首节："→"首节：／歌队：……"。理由：与本作品其他合唱歌（如 @726）的标注顺序统一。
- @974–975：原译"落到你身上的，并不只有你，也不只有你的亲人，这些沉痛的悲伤"→"这些沉痛的悲伤并非只落在你身上，也并非只落在你的亲人身上"。理由：原句"落到你身上的，并不只有你"语义不通。
- @976–977：原译"那霹雳也越过弗里吉亚人那盛产果实的田野"→"那霹雳也渡海而去，落到弗里吉亚人那盛产果实的田野"。理由：διέβα … πρὸς εὐκάρπους γύας 意为"越海到达"，原译"越过田野"误解了方向。
- @1010：原译"我已一无所有"→"我什么都不是了"。理由：οὐδέν εἰμ’ 意为"我已不复为人／形同乌有"，并非指财物。
- @1021：原译"神的居民们"→"住在神地的百姓"。理由：λαὸς οἰκήτωρ θεοῦ 指居住在神所在之地的民众，原译措辞不当。
- @1030：原译"也在柱廊环绕的殿宇里布下守卫"→"也私下在……布下守卫"。理由：漏译 ἰδίᾳ。
- @1037：原译"过错"→"过失"。理由：ἁμαρτία 按术语表译"过失"，与本作品 @789 统一。
- @1111–1121（注）：原注"阿喀琉斯是埃阿科斯的曾孙"→"阿喀琉斯是埃阿科斯之孙"。理由：阿喀琉斯为佩琉斯之子，佩琉斯为埃阿科斯之子，原注世系有误。
- @1203–1206：重组整段收场诗译句。理由：改写以避免与已出版译本雷同（欧里庇得斯多部剧共用的这段收场诗，旧译措辞流传较广）。
- @1118：〔存疑〕ἀλλὰ κεραυνῷ πρόσθεν ὀλέσθαι 的主语，译文取赫尔弥奥涅（"让她早先就死于雷霆"）；也可理解为承前的"我的家族"。未改动。
